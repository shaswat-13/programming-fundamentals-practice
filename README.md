# Programming Fundamentals Practice

This repository contains a collection of small programs and experiments written while learning the fundamentals of **C, C++, and Python**.

The programs were created alongside coursework and self-study to reinforce core programming concepts such as control flow, functions, arrays, and object-oriented programming. Each file focuses on implementing a specific concept or solving a small programming problem.

Although the programs are simple, they played an important role in strengthening my understanding of programming fundamentals and developing problem-solving skills.

## Purpose of This Repository

While learning programming, I intentionally built small programs to **practice individual concepts in isolation**.  

Instead of only reading theory, these programs allowed me to:

- test programming logic
- understand how syntax behaves in real code
- debug common errors
- reinforce object-oriented programming concepts
- practice writing clean and structured programs

This repository represents that **hands-on experimentation phase** of learning programming.

## Languages Used

- **C**
- **C++**

## Repository Structure

Each file focuses on a specific concept or exercise.

Example programs include:

- **Hello World Programs**  
  Basic introduction to language syntax.

- **Guessing Game (C)**  
  A simple interactive program demonstrating loops and conditionals.

- **Sorting Arrays (C)**  
  Basic array manipulation and algorithmic thinking.

- **Rock Paper Scissors (Python)**  
  A small game demonstrating control flow and randomness.

- **Function Overloading (C++)**  
  Practice with object-oriented programming concepts.

- **Namespaces (C++)**  
  Demonstrates scope management in C++.

- **Reference Variables (C++)**  
  Understanding references and memory behavior.

These exercises helped reinforce the fundamentals required for larger software projects.
